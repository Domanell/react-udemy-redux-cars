# React Redux Cars Application

This is a car inventory management application built with React, Redux Toolkit, and Create React App. It allows users to add cars with their costs, search through the car list, and calculate the total value of filtered cars. The application demonstrates the use of modern React features, Redux for state management, memoization with selectors, and Bulma CSS for styling.

## Features

- **Car Management**: Add cars with name and cost to your inventory.
- **Smart Search**: Filter cars by name with real-time search functionality.
- **Total Value Calculation**: Automatically calculates the total cost of filtered cars.
- **Highlight Matching Cars**: Cars matching the form input are highlighted in the list for better visual feedback.
- **State Management**: Centralized state management using Redux Toolkit slices.
- **Memoized Selectors**: Uses `createSelector` for optimized performance when filtering cars.
- **Automatic Form Reset**: Form fields automatically clear after adding a car.
- **Responsive Design**: Styled with Bulma CSS for a clean and modern UI.

## Technologies Used

- **React**: For building the user interface.
- **Redux Toolkit**: For state management and efficient Redux development.
- **Create React App**: For bootstrapping and building the application.
- **Bulma CSS**: For styling the application with a modern CSS framework.
- **Immer**: Built into Redux Toolkit for immutable state updates.
- **nanoid**: For generating unique IDs for cars.

## Store

The Redux store is configured using `configureStore` from Redux Toolkit. It includes two main slices:

- **Cars Slice**: Manages the list of cars and search functionality.
- **Form Slice**: Manages the state of the car form inputs.

The store is set up to handle both synchronous state updates efficiently with automatic Immer integration for immutability.

## Slices

### Cars Slice

The `carsSlice` manages the state of cars and search functionality. It includes:

**Initial State**:

- `searchTerm`: Current search query string.
- `data`: Array of car objects.

**Reducers**:

- `changeSearchTerm`: Updates the search term for filtering cars.
- `addCar`: Adds a new car to the inventory with a unique ID generated by `nanoid()`.
- `removeCar`: Removes a car from the inventory by ID.

Each car object contains:

- `id`: Unique identifier (generated by `nanoid()`).
- `name`: Name of the car.
- `cost`: Cost of the car (number).

### Form Slice

The `formSlice` manages the state of the car form inputs. It includes:

**Initial State**:

- `name`: Current value of the name input field.
- `cost`: Current value of the cost input field.

**Reducers**:

- `changeName`: Updates the name field value.
- `changeCost`: Updates the cost field value.

**Extra Reducers**:

- Listens to the `addCar` action from the cars slice to automatically reset form fields to their initial state after a car is added.

This cross-slice communication demonstrates Redux's ability to handle related state updates across different slices.

## Components

### CarForm

Provides a form interface for adding new cars to the inventory.

**Features**:

- Controlled inputs for car name and cost.
- Dispatches `changeName` and `changeCost` actions on input changes.
- Dispatches `addCar` action on form submission.
- Automatically resets form fields after submission via extra reducers.

### CarSearch

Provides a search input for filtering the car list.

**Features**:

- Controlled input connected to Redux state.
- Dispatches `changeSearchTerm` action on input changes.
- Filters are applied in real-time.

### CarList

Displays the list of cars with delete functionality.

**Features**:

- Uses memoized selector (`createSelector`) to filter cars based on search term for optimal performance.
- Highlights cars that match the current form name input (bold styling).
- Each car entry shows name, cost, and a delete button.
- Dispatches `removeCar` action when delete button is clicked.

**Performance Optimization**: The component uses `createSelector` from Redux Toolkit to create a memoized selector that only recalculates filtered cars when the car data or search term changes.

### CarValue

Displays the total cost of all filtered cars.

**Features**:

- Calculates the sum of costs for cars matching the current search term.
- Updates automatically when cars are added, removed, or search term changes.
- Uses a selector with destructuring to access nested state properties.

## Memoization and Performance

The application demonstrates important Redux performance patterns:

- **Memoized Selectors**: The `CarList` component uses `createSelector` to create a memoized selector that filters cars. This prevents unnecessary recalculations when unrelated state changes.
- **Selective Re-renders**: Components only re-render when their selected state actually changes.
- **Structured Selectors**: The `CarValue` component shows how to use object destructuring in selectors for cleaner code.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd redux-cars
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

4. Open the application in your browser at [http://localhost:3000](http://localhost:3000).
